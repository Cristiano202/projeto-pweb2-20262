# Frontend - Projeto PWEB2

Interface web desenvolvida em React + TypeScript + Vite para consumir a API Spring Boot.

## Tecnologias

- React
- TypeScript
- Vite
- React Router
- Redux Toolkit
- Axios
- Storybook

## O que foi feito até agora

- Configuração inicial do projeto com Vite e TypeScript
- Configuração de rotas e estrutura do Redux
- Configuração do Axios e proxy do Vite para a API (`localhost:8080`)
- Tipagens TypeScript mapeadas a partir do Swagger (`src/types/`)
- Serviços de comunicação com a API (`src/services/`)
- Componentes base de UI (`Button`, `Input` e `Modal` em `src/components/ui/`)

## Como rodar

```bash
cd frontend
npm install
npm run dev
```

Acesse `http://localhost:5173` no navegador.
